## 🧱 โครงสร้างโปรเจกต์

```
krujr-portfolio/
├── index.html            ← หน้า GitHub Pages: เปิดเว็บไซต์จริง (Apps Script) เต็มจอ
├── demo/
│   └── index.html        ← เดโมโหมดตัวอย่าง ทดลองหลังบ้านได้ (รหัส 1234)
├── apps-script/
│   ├── code.gs           ← หลังบ้าน: Sheets, Drive, ล็อกอิน, CRUD, อัปโหลด
│   └── index.html        ← หน้าเว็บ: Vue 3 + Tailwind + Lucide (ไฟล์เดียว)
├── tools/
│   └── selftest.gs       ← ชุดทดสอบระบบอัตโนมัติ 61 รายการ
└── docs/
    └── INSTALL.md        ← คู่มือติดตั้งทีละขั้น
```

ไฟล์ `apps-script/index.html` (และ `demo/index.html` ซึ่งเป็นไฟล์เดียวกัน) ทำงานได้สองโหมด: เปิดใน Apps Script จะเชื่อมข้อมูลจริงผ่าน `google.script.run` ส่วนเปิดที่อื่น (เช่น GitHub Pages) จะเป็นโหมดตัวอย่าง ทดลองเข้าหลังบ้านด้วยรหัส `1234` ได้ โดยข้อมูลไม่ถูกบันทึกจริง

## 🚀 ติดตั้งแบบย่อ

1. สร้าง Google Sheet แล้วเปิด **ส่วนขยาย → Apps Script**
2. วาง `apps-script/code.gs` และสร้างไฟล์ HTML ชื่อ `index` แล้ววาง `apps-script/index.html`
3. รันฟังก์ชัน `setup` และกดอนุญาตสิทธิ์
4. **ทำให้ใช้งานได้ → เว็บแอป** (เรียกใช้ในฐานะ: ฉัน / ผู้มีสิทธิ์เข้าถึง: ทุกคน)
5. เข้าหลังบ้านด้วยรหัส `1234` แล้วเปลี่ยนรหัสทันที

รายละเอียดทั้งหมดอยู่ใน **[docs/INSTALL.md](docs/INSTALL.md)**

## ✅ การทดสอบ

`tools/selftest.gs` ทดสอบกับ Sheets และ Drive จริง แล้วลบข้อมูลทดสอบทิ้งให้เอง ครอบคลุม:
บันทึกโปรไฟล์ · อัปโหลดรูปและเอกสาร · CRUD ครบ 8 หมวด · ข่าวฉบับร่างไม่แสดงบนหน้าเว็บ · ฟอร์มติดต่อและการกันบอท · จัดการข้อความ · การปฏิเสธคำขอที่ไม่ได้ล็อกอิน

> หลังทดสอบเสร็จ ให้ลบ `selftest.gs` ออกจากโปรเจกต์ เพราะฟังก์ชันในโปรเจกต์ Apps Script ถูกเรียกจากหน้าเว็บได้
